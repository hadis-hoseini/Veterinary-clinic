## 📘 توضیح کلی پروژه
این پروژه یک سامانه نرم‌افزاری برای مدیریت کامل یک کلینیک دامپزشکی است.  
هدف این سیستم، مدیریت پرونده حیوانات، ثبت نوبت‌ها، مدیریت دامپزشکان، ثبت سوابق پزشکی و صدور صورتحساب برای خدمات ارائه‌شده می‌باشد.

---

## 🎯 اهداف پروژه
- مدیریت پرونده حیوان (Animal Profile)
- ثبت و مدیریت نوبت‌ها (Appointments)
- ثبت خدمات پزشکی (Vaccination, Surgery, Treatment)
- مدیریت دامپزشکان
- نگهداری سوابق پزشکی حیوان
- صدور صورتحساب
- ارسال پیامک برای یادآوری نوبت‌ها (Feature)
